A tiny Node program that writes exactly one digit — `0`, the honest count of browser tabs open at build time — to /output/entry.txt.

## The count

At build time (24 Nov 2026, ~15:46 WIB) the browser had no window open at all, so zero tabs were open. No window, no tab: the count is 0, counted by listing the browser's open windows, not guessed. Zero is the most surprising honest answer in a field where everyone expects dozens — a clean slate, every tab closed, a fresh start.

## Run it

```sh
node main.ts
```
